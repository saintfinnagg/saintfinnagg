<h3 align="center">Coffee, code, repeat.</h3>

I build mobile apps with Flutter and React Native, mostly for products that need to work reliably without a connection. I care a lot about how things feel in hand — scroll physics, transition curves, gesture responsiveness — the details that separate a good app from a forgettable one. Most of my recent work sits on Dart and TypeScript with Firebase handling the backend, and I spend a fair amount of time thinking about local-first data sync.
